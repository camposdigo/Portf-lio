# Rodrigo Campos — Portfolio

Portfólio profissional de Rodrigo Campos Cordeiro, Analista Júnior de AI & Analytics e estudante de Ciência da Computação na FIAP.

O site apresenta experiência profissional, serviços e projetos selecionados nas áreas de Python, automação, Inteligência Artificial, APIs e dados.

## Projetos em destaque

- [PDF Flow](https://github.com/camposdigo/pdf-flow) — automação e processamento de documentos PDF com Python, Flask e OCR.
- [AutoSubtitle AI](https://github.com/camposdigo/autosubtitle-ai) — transcrição, tradução, legendas e dublagem automatizada de vídeos.
- [Mission Control AI](https://github.com/camposdigo/mission-control-ai) — aplicativo mobile de monitoramento com React Native, Expo e TypeScript.

## Publicação com GitHub Pages

O site é estático e pode ser publicado diretamente pelo GitHub Pages usando a branch `main` e a pasta `/ (root)`.

Em `Settings > Pages`, selecione `Deploy from a branch`, escolha `main` e `/ (root)` e salve.
